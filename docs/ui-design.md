# Flow Clock — UI 设计规范

> 最后更新：2026-05-29  
> 风格：**简约 + 小红书美学**（莫兰迪色、留白、圆角、柔和阴影）

---

## 1. 设计原则

| 原则 | 说明 |
|------|------|
| **少即是多** | 一屏只做一件事；计时页无多余按钮 |
| **小红书感** | 莫兰迪配色、大圆角（16dp）、轻阴影、插画感 |
| **每日不重样** | 星期一到日各一种植物主角，背景色随日变化 |
| **不逼视觉** | 无红字警告、无倒计时压迫感（仪式阶段尤其） |

## 5. 每日植物轮换（一周不重样）

App 根据 `DateTime.weekday` 自动切换：

| weekday | 文件 | 植物 |
|---------|------|------|
| 1 周一 | `monday_sakura.svg` | 樱花 |
| 2 周二 | `tuesday_succulent.svg` | 多肉 |
| 3 周三 | `wednesday_sunflower.svg` | 向日葵 |
| 4 周四 | `thursday_bamboo.svg` | 竹子 |
| 5 周五 | `friday_lavender.svg` | 薰衣草 |
| 6 周六 | `saturday_cactus.svg` | 仙人掌 |
| 7 周日 | `sunday_maple.svg` | 红枫 |

**成长阶段**：`DailyTreeWidget` 按 k=0~8 从底部裁剪生长；k=4 半日冠光晕、k=8 满冠金效。背景色和植物品种按星期变。

资源路径：`assets/plants/week/`

## 7. Flutter 实现参考

```dart
// 当日主题
class DayTheme {
  final String plantAsset;
  final Color primary;
  final Color background;
  final String plantName;

  static DayTheme forDate(DateTime d) {
    switch (d.weekday) {
      case DateTime.monday:    return DayTheme('assets/plants/week/monday_sakura.svg', ...);
      case DateTime.tuesday:   return DayTheme('assets/plants/week/tuesday_succulent.svg', ...);
      // ...
    }
  }
}
```

```yaml
# pubspec.yaml
flutter:
  assets:
    - assets/plants/week/
```

依赖：`flutter_svg` 渲染 SVG 植物。
