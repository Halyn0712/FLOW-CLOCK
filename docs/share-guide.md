# Flow Clock — 分享功能指南

> 最后更新：2026-05-29

## 触发时机

| 时机 | 是否可分享 | 说明 |
|------|-----------|------|
| k=8 满冠神树收工 | ✅ **主入口** | 收工仪式页大按钮「分享我的自律之树」 |
| 任意日等级收工（k≥1） | ✅ 可选 | 树未满冠也可分享当前进度（V1） |
| 月历单日长按 / 详情分享 | ✅ V1 | 回顾历史某一天 |
| 月末森林全景 | ✅ V2 | 长图「本月自律森林」 |

---

## 分享内容：自律分享卡（Share Card）

系统自动生成一张 **1080×1440** 竖图（适配小红书 3:4），包含：

```
┌─────────────────────────┐
│  2026.05.29  巅峰日 🔥   │
│                         │
│      ✨🌳 满冠神树 ✨     │  ← DailyTree 当前形态
│                         │
│   专注 8h · 8 块 · M=8   │
│   连续巅峰日 ×3          │
│                         │
│  「今天没有逼自己，        │  ← 用户 Reflection（可选）
│    但树长满了。」         │
│                         │
│        Flow Clock       │  ← 低调水印
└─────────────────────────┘
```

用户可在分享前：
- 编辑/隐藏 Reflection
- 切换卡片样式（V2：简约 / 森林 / 深色）✅
- 选择预填文案风格

## 分享平台（Android 系统分享）

使用 Flutter **`share_plus`** 调起 Android 原生分享面板，**无需接入各平台 SDK**，用户已安装的 App 都会出现在列表里：

| 平台 | 分享方式 | 推荐内容 |
|------|---------|---------|
| **微信** | 分享给朋友 / 朋友圈 | 分享卡图片 + 短文案 |
| **小红书** | 发布笔记 | 分享卡图片 + 长文案 + 话题标签 |
| **QQ / QQ空间** | 分享图片 | 分享卡 + 短文案 |
| **微博** | 发微博 | 分享卡 + `#FlowClock# #自律#` |
| **保存到相册** | 系统「保存」或文件管理 | 仅图片，用户自行发帖 |
| **其他** | 钉钉、飞书、Bluesky… | 凡支持接收图片的 App 均可 |

> **说明**：不上架应用商城的 APK 无法做微信深度集成（如小程序跳转），但**系统分享发图到微信/小红书完全够用**，也是 Forest、番茄类 App 的常见做法。

## 预填文案模板

### 短版（适合微信）

```
🌳 今日自律之树满冠了！
8 小时专注 · 8 块心流
Flow Clock 见证我的成长 ✨
```

### 长版（适合小红书）

```
今天把这棵自律之树养满了 🌳✨

📊 8 小时深度专注 · 8 个心流块
🌱 从微启动到满冠，没有逼自己，但树长成了

自律不是硬扛，是找到属于自己的节奏。

#FlowClock #自律 #专注 #心流 #今日之树 #高效工作日
```

用户分享前可编辑文案；也可选择「只发图不带字」。

## 技术实现

### 依赖

```yaml
dependencies:
  share_plus: ^10.0.0
  path_provider: ^2.1.0
  # 分享卡渲染
  # RepaintBoundary + dart:ui Image.toByteData
```

### 核心流程

```
收工仪式 (k=8)
    ↓
ShareCardWidget → RepaintBoundary → PNG 写入缓存
    ↓
Share.shareXFiles([XFile(pngPath)], text: caption)
    ↓
Android 系统分享面板 → 用户选微信 / 小红书 / …
```

### 权限（AndroidManifest）

```xml
<!-- 分享卡写入缓存目录，一般不需要额外权限 -->
<!-- 若「保存到相册」：Android 10+ 使用 MediaStore，无需 WRITE_EXTERNAL_STORAGE -->
```

### 代码结构

```
lib/features/share/
  share_card_widget.dart    # 分享卡 UI
  share_card_renderer.dart  # Widget → PNG
  share_service.dart        # share_plus 封装
  share_captions.dart       # 预填文案模板
```

## 隐私原则

- 分享内容**全部本地生成**，不上传服务器
- 默认分享卡**不含**具体任务标签内容（防泄露工作细节）；用户可在设置开启「分享时带上任务标签」
- Reflection 默认展示，用户可一键隐藏
