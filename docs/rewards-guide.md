# Flow Clock — 自定义兑换奖励指南

> 最后更新：2026-05-29（v2 — 确认收货制）

## 概述

除 DailyTree 虚拟奖励外，App 提供 **两级现实兑换奖励**，由用户自己定义「赢了什么」。  
**不是时间过了就算**—— 必须 **8 小时满冠 + 手动确认收货**，且凭**自觉**：觉得今天不够自律，就不点收货，这一天**不计入**连续天数。

---

## 核心变量

| 变量 | 含义 |
|------|------|
| **S** | 当前连续有效自律天数（Streak） |
| **Claim** | **确认收货** —— 用户主动点击，表示「今天这棵树我认账」 |
| **D_valid** | 有效自律日，需**同时满足**下面两条 |
| **R1 / R2** | 一级 / 二级奖励内容（用户自定义，兑换后清空） |
| **P1 / P2** | 一级进度 0→5 / 二级进度 0→2 |

**有效日公式（两条缺一不可）：**

\[
D_{valid} = (k = 8) \land Claim
\]

| 条件 | 含义 |
|------|------|
| **k = 8** | 当天完成 8 块、8 小时，DailyTree **满冠神树** |
| **Claim** | 用户在收工页点击 **「确认收货 · 今日之树」** |

- 只完成 6h、提前收工 → k<8 → **不能收货**，不计入 S
- 完成 8h 但自觉不够自律、不点收货 → **不计入** S（App 不替你做主）
- 当天 24:00 前未收货 → 该日视为无效，连续天数中断

**兑换条件：**

\[
\text{二级可兑换} \Leftrightarrow P_2 \geq 2 \land R_2 \neq \emptyset
\]

\[
\text{一级可兑换} \Leftrightarrow P_1 \geq 5 \land R_1 \neq \emptyset
\]

每收到一次货（一次 \(D_{valid}\)）→ S+1，P1+1，P2+1。

---

## 确认收货流程（核心）

```
完成第 8 块 → 满冠神树 ✨
        ↓
收工仪式页（day_complete 闹钟已响）
        ↓
用户可选：写 Reflection、分享
        ↓
[ 🌳 确认收货 · 今日之树 ]  ← 只有 k=8 时出现
        ↓
    用户自觉判断：
    ├─ 今天确实自律了 → 点击 → D_valid ✓ → S+1, P1+1, P2+1 → 写入月历
    └─ 今天不够自律   → 不点   → 不计入奖励，月历该日无「收货」标记
        ↓
若 P2=2 → 可兑换二级；P1=5 → 可兑换一级
```

**设计意图**：  
App 只提供「满冠」的客观条件；**是否算自律的一天，由你点不点收货决定**—— 不惩罚、不追问，但不点就不进 streak。

## 设置与兑换

### 1. 自定义奖励（设置 → 我的奖励）

```
🥈 二级奖励（连续收货 2 天）  [ 喝一杯奶茶 ]
🥇 一级奖励（连续收货 5 天）  [ 看一集喜欢的剧 ]
```

未填写 → 不可兑换，进度条仍展示。

### 2. 连续收货积累

| 事件 | 结果 |
|------|------|
| 收货日（D_valid） | S+1，P1+1，P2+1 |
| 未收货（k<8 或未点 Claim） | **S=0，P1=0，P2=0**（连续中断） |
| 兑换二级 | R2 清空，P2=0，需重填 R2 |
| 兑换一级 | R1 清空，P1=0，需重填 R1 |

### 3. 兑换仪式

1. 点击「兑换」→ 展示「你赢得了：XXX」
2. 确认「我兑换了」→ 清空对应 R，记录历史
3. 提示填下一个奖励目标

## 场景举例

| 场景 | k | 点收货？ | 计入 S？ |
|------|---|---------|---------|
| 满冠，自觉今天很好 | 8 | ✅ | ✅ |
| 满冠，但觉得水时长/走神 | 8 | ❌ 不点 | ❌ |
| 只做了 5h 就收工 | 5 | 无按钮 | ❌ |
| 连续 2 天都收货 | — | — | S=2 → 可兑二级 |
| 第 3 天未收货 | — | — | S 归零，重新攒 |

## 与 DailyTree / 月历

| 状态 | 月历显示 | 计入一级/二级 |
|------|---------|--------------|
| k=8 + 已收货 | 满冠树，金边/巅峰标记 | ✅ |
| k=8 + 未收货 | 灰态或「待收货」（可选） | ❌ |
| k<8 收工 | 当日进度快照（可选） | ❌ |
