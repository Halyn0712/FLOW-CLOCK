# Changelog

## 0.6.0 (2026-05-29) — 首个可安装 MVP

本版本包含完整核心循环：动量仪式计时、DailyTree 生长、确认收货、奖励兑换、月历、分享（单日/月末长图/三套皮肤）、后台精确闹钟。

### 新增
- **分享卡 3 套皮肤**：简约 / 森林 / 深色，预览页可切换
- 森林皮肤：绿意渐变 + 植物装饰边框
- 深色皮肤：暗色背景 + 满冠金色强调

## 0.5.0 (2026-05-29)

### 新增
- **月末森林长图**：月历页一键生成整月回顾竖图（约 1080px 宽）
- 含月统计（收货/专注/巅峰日）、完整月历格、植物 emoji 与 k 值
- 巅峰日 ≥15 显示「高效之月」徽章
- 月历 AppBar 🌲 按钮 + 「分享本月自律森林长图」入口

## 0.4.0 (2026-05-29)

### 新增
- **月历历史日分享**：单日详情页「分享」按钮 + 长按月历格快速分享
- 历史日分享卡自动使用当日植物主题与日等级，文案含日期「回顾」

## 0.3.1 (2026-05-29)

### 新增
- **后台精确闹钟**：心流/休息/半日锚点阶段预约系统通知（`exactAllowWhileIdle`）
- App 被杀或锁屏后到期仍响铃；重启后根据 `phaseEndsAt` 自动对齐会话
- 回到前台时 `reconcileOnResume` 补跑错过阶段，避免计时漂移

### 修复
- 阶段完成 `switch` 误 fall-through（仪式结束可能误触发心流闹钟）
